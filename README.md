# RCT sample-size calculator

Static, standalone HTML/JavaScript application. No dependencies, backend, analytics, or patient data.

## GitHub Pages

1. Create a public repository, e.g. `rct-calculator`.
2. Upload `index.html` (and optionally `.nojekyll`) to the default branch root.
3. Under **Settings > Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then save.
4. The site will appear at `https://<owner>.github.io/rct-calculator/` once deployment succeeds.

The embedded scenarios are hypothetical. The results are planning calculations, not evidence of clinical efficacy.
